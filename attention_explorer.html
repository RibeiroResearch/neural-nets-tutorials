Attention by Hand

Nothing here is trained. Every projection is set by hand, and each patch token carries seven numbers whose meanings you can read: [R, G, B, x, y, |p|², 1]. Click a patch to see where it attends.

The scene — 8 × 8 patches, 64 tokens

The outlined patch is the query — the one doing the looking. Brightness over every other patch is how much weight the query sends there, so the grid keeps the image's own layout but is coloured by attention rather than by colour.
